# libfprint-elanmoc2

Community support for ELAN Match-on-Chip 2 fingerprint readers that are not
recognized by the stock `libfprint` package.

## Currently supported device

| Device | USB ID |
|---|---|
| ELAN Match-on-Chip 2 | `04f3:0ca0` |

Detected by:

```text
Bus 001 Device 002: ID 04f3:0ca0 Elan Microelectronics Corp. ELAN:ARM-M4
